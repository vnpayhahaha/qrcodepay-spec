# Security Policy

Please do not open public issues for suspected vulnerabilities involving keys, provider execution, signature verification, replay risk, or privacy leaks.

Report security concerns to:

security@qrcodepay.ai

Do not include secrets or real credentials in reports.

## Scope

- Payment Mandate schema
- Audit Record schema
- Provider Interface
- Threat Model

## Out of Scope

- closed provider infrastructure
- partner rails
- user-specific support
