# Contributing

Thanks for helping improve the QRCodePay Open Specification.

## Scope

This repository covers the open specification only. Contributions are welcome for:

- Payment Mandate schema
- Audit Record schema
- examples
- threat model
- provider interface
- documentation

Closed provider implementation is out of scope.

## Do Not Submit

Do not submit real API keys, partner details, routing logic, risk rules, funding operations, or merchant data.

## Process

Open an issue before major changes so the scope and compatibility impact can be discussed first.

Schema changes must include clear examples and backwards compatibility notes. If a change breaks existing fields or semantics, call that out explicitly.
